Customers who file more than three return requests within any rolling six-month window are flagged for manager review. Their next return request is held — not denied, not approved — until a manager confirms.

The rule isn't about denying refunds; it's about pattern recognition. Three returns in six months is the threshold where the data starts suggesting either a chronic product-fit problem (which the manager can address with a different recommendation) or an abuse pattern (which the manager should triage). Either way, the next return goes through human review before the system commits.

**Lesson I keep:** Count the customer's returns in the past 6 months. ≥4 (i.e., this one would make it the 4th or more) → hold for manager. <4 → process normally per other rules.
