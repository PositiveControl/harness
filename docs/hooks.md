# Fabrication-catcher hook registry

_Generated by `scripts/gen_hook_docs.py` from `src/harness/orchestrator/hooks.py:HOOK_SHAPES` and the default hook pipeline with all opt-in catchers enabled. Do not hand-edit; edit the source registry and re-run the generator._

Hooks dispatch in the order shown within each phase — first-match semantics, so a reply that trips two catchers gets the FIRST one's nudge. Phase ordering: `post_model` → `bail` → `pre_tool` → `post_tool` → `finalize`.
